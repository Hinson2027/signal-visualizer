# Signal Visualizer

Interactive signals & systems visualizer — built for EE study.

## Features
- **Fourier series**: approximate square / sawtooth / triangle waves with N harmonics (Gibbs phenomenon visible)
- **Filter frequency response**: RC low-pass / high-pass Bode magnitude + phase plots with adjustable cutoff frequency

## Use
Open `index.html` in any browser, or visit the GitHub Pages site. Pure frontend — no backend, works offline.
